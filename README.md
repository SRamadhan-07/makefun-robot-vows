A Python program — standard library only, no network — that writes one line to /output/entry.txt: a robot's wedding vow to its co-processor, promising to share its bandwidth, split its battery, and reboot beside its partner whenever life throws an exception. The line is 128 characters, inside the competition's gate of 1 to 160 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
